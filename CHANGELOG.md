# Changelog

## 1.0.0 (2026-05-12)

Initial release.

- Full-screen VGA hex viewer and editor
- Hex and ASCII editing modes
- Goto offset dialog with relative offset support
- Hex and ASCII pattern search (F6/F7/F8)
- Selective byte save via fseek/fwrite
- Unsaved changes protection on exit
- DJGPP cross-compilation support (Linux to DOS)
